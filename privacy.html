NudgeSheet Privacy Policy

Effective date: September 13, 2026

NudgeSheet is a Google Sheets add-on published by NudgeSheet. It adds follow-up reminders and actions on top of a spreadsheet the user already owns. This policy describes the limited information NudgeSheet processes.

Google Sheets data

NudgeSheet reads the spreadsheet columns that the user maps in order to display follow-ups and perform requested actions (marking a follow-up done, snoozing it, or refreshing the view). Lead names, companies, email addresses, notes, spreadsheet content, spreadsheet IDs, and raw error messages are never sent to NudgeSheet's telemetry service. Lead data always remains in the user's own Google Sheet.

Column mapping is stored in that spreadsheet's document properties, scoped to the spreadsheet itself. Reminder settings and delivery state are stored in the installing user's Apps Script user properties, scoped to that user's Google account.

The daily reminder email, when enabled, is sent only to the Google user who enabled it. NudgeSheet does not read Gmail and does not send email to leads or customers.

Limited usage statistics

NudgeSheet collects a small set of anonymous usage events to understand whether the product is being used and to improve reliability:

  • A randomly generated install identifier that is not derived from an email address or any Google account identifier.
  • One of six event names: install, mapping_completed, sidebar_opened, action_done, action_snooze, or digest_sent.
  • The event timestamp.
  • The application identifier nudgesheet.

This telemetry payload never contains lead data, spreadsheet content, a spreadsheet identifier, a Google account email address, or a raw error message. The data is not used for advertising, is not sold, and is not shared with third parties other than the infrastructure provider used to store it (Supabase, acting solely as a data processor).

Retention: usage event records are retained for up to 24 months from the event date, after which they are deleted. Aggregated counts derived from this data (e.g. "N installs used mapping this month") may be retained longer for product planning, without any per-install identifier attached.

Security

Telemetry is transmitted over HTTPS to a collector that authenticates each application with a dedicated secret key and rejects any event name, field, or application identifier that is not on an explicit allowlist. The underlying database has row-level security enabled with no public read or write access; only the collector service can write to it.

NudgeSheet's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your choices

Uninstalling the add-on stops all data collection going forward. Column mappings and reminder settings are removed when the add-on is uninstalled from a spreadsheet or Google account, following normal Apps Script property lifecycle behavior.

Changes to this policy

Material changes to what is collected or how it is used will be posted on this page with an updated effective date before the changed processing begins.
